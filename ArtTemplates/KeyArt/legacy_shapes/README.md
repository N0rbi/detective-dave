# Legacy templates: one picture per key size

These are the old templates (8 shapes, in `pixel16` and `hires64`). The game now draws every normal key from one 9-sliced Box and the Enter from one Enter picture (see `../README.md`), so new art does not need them.

Use them only for art that still goes into the optional Shape Overrides of a Key Art style, where a picture is made for one exact key size.

`../make_templates.py` recreates them.
